# Common Good Network

## Overview

Common Good Network is a 501(c)(3) community foundation formerly known as Kentucky Cannabis Foundation.

Lauren serves as Board President.

## Purpose

Build education, community benefit, access, and infrastructure around wellness, cannabis education, and public good initiatives.
