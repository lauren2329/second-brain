# raw / chat

Captures from text messages, DMs, and group chats worth keeping.

**What goes here:** screenshots, pastes, or summaries of important exchanges — decisions made via text, key info shared in a thread. Also houses the Codex/ChatGPT "Chat Summary" series (see [[Chat Summary Index - 2026-07-25 to 2026-07-27]]) and raw message exports.
**Process to:** `wiki/people/` for relationship context, `wiki/projects/` for decisions.
**Naming:** `YYYY-MM-DD chat [person or group].md` (the Chat Summary series uses its own established `Chat Summary - YYYY-MM-DD - Topic.md` naming — kept as-is for consistency with its existing index).
